2. There is something unusual about this pod

Earlier you showed:

dynatrace  dynakube-oneagent-dsw22  0/1  Completed  3  64d

That's unusual for something called dynakube-oneagent.

It's been sitting in:

Completed
AGE: 64d

yet MCO is attempting to evict it during every drain.

And the eviction request succeeds:

evicting pod dynatrace/dynakube-oneagent-dsw22

but the pod doesn't actually disappear, causing:

context deadline exceeded

This strongly suggests we should inspect why that completed pod cannot be deleted/terminated.

Potential causes include:

a finalizer
Dynatrace operator behavior
stale/orphaned pod
pod stuck in terminating state
unusual owner/controller relationship
kubelet/container-runtime issue

We shouldn't assume which one yet.

3. Check whether it has a deletion timestamp

This command is particularly useful:

oc get pod dynakube-oneagent-dsw22 -n dynatrace \
  -o jsonpath='{.metadata.deletionTimestamp}'
echo
If you get something like:
2026-08-22T00:25:...

then the pod is already being deleted but is stuck terminating.

That's a different situation from an eviction simply being rejected.

If it's blank, then we'll inspect why the eviction isn't resulting in deletion.

4. Check finalizers

  -o jsonpath='{range .metadata.finalizers[*]}{.}{"\n"}{end}'

If you see something such as a Dynatrace-related finalizer, don't remove it yet.

5. Check Dynatrace ownership

Run:

oc get pod dynakube-oneagent-dsw22 -n dynatrace \
  -o jsonpath='{range .metadata.ownerReferences[*]}{.kind}{" "}{.name}{" controller="}{.controller}{"\n"}{end}'

For example, if it returns:

DaemonSet dynakube-oneagent controller=true

then we know the pod is managed by a DaemonSet.

If it returns:

Job ...

or something else, the remediation will be different.

6. Don't delete it yet

Although the pod is Completed, I don't want you to immediately run:

oc delete pod dynakube-oneagent-dsw22 -n dynatrace

because this is a production ROSA control-plane upgrade and Dynatrace is an installed operator.

It may be perfectly safe to delete this particular stale Completed pod, but let's confirm its owner/finalizer first.
